# Modelo operativo

## Objetivo

Convertir la boveda principal en una base de conocimiento util para trabajar, aprender, consultar y documentar sin perder la riqueza ya acumulada.

## Cadencia recomendada

- Captura diaria: libre, rapida y con baja friccion.
- Ingesta: una fuente o grupo pequeno de fuentes cada vez.
- Consolidacion: al cerrar una sesion importante de proyecto.
- Mantenimiento ligero: semanal o tras cambios grandes.
- Mantenimiento profundo: mensual o cuando haya muchas capturas sin procesar.

## Roles

- Humano: selecciona prioridades, valida criterios, decide que merece consolidarse.
- Agente: resume, enlaza, ordena, detecta duplicados, propone sintesis y registra cambios.
- Boveda: conserva fuente, razonamiento, decision y continuidad.

## Definicion de terminado

Una mejora documental esta terminada cuando:

- La fuente original esta preservada si procede.
- La nota curada tiene fecha, tipo, estado y fuentes.
- El contenido reutilizable esta enlazado desde conceptos, entidades, sintesis o proyectos.
- Las dudas y limites quedan visibles.
- El indice y el log se actualizan si el cambio afecta a la estructura o a una decision relevante.
