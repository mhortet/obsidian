## Resumen
Configuración de la central y monitores Dragër Infinity para asignación de nuevos nombres y reconocimiento por la cental
## Descripción

Monitores: Infinity Delta XL
Central: Infinity Central Station Wide (instalación 2020/2021)

### Pasos para configurar monitor:
- Configurar Monitor
- Pass 4712
	- Ajustes de red
		- Configuración de red
		- Cambiar nombre con el teclado inferior y botonera
### Pasos para configurar central:
- Configurar sistema
- Pass: SUPER
	- Pantalla principal
	

# ¡Importante!

Para apagar la central, nunca hacerlo directamente, se puede dañar el HD

### Para apagar:
- Configurar sistema
	- Bio
	- Pass: SUPER
	- Consola de sistema
		- introducir comando stopcentral, esperar salgan varias lineas con un ok en verde, y despúes se puede apagar el interruptor.
