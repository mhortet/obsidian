# Notas diarias

Carpeta para registro cronologico personal o de trabajo.

Usar cuando una nota tenga valor como seguimiento diario, continuidad de sesion, bitacora ligera o registro temporal que no encaje aun como fuente, concepto, analisis o proyecto.
