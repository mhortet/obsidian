La configuración final permitió arrancar la aplicación, pero este procedimiento
no se considera todavía cerrado para producción. El modelo objetivo sigue
siendo:

- Administradores y `SYSTEM`: control total;
- Usuarios: lectura de la configuración;

un proceso elevado y restaurar o conservar automáticamente las ACL previstas,
sin depender de cambios manuales permanentes de propietario.

1. crear un commit documental separado;
2. subir la rama;
3. abrir un pull request en borrador hacia `main`;
4. revisar CI, seguridad y diff completo antes de marcarlo como listo;
5. valorar añadir `python -m unittest discover -s tests -v` al workflow de CI.
