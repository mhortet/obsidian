# Historico documental
[[masgesth]]
Fecha de revision: 2026-05-30

## Objetivo

Este directorio conserva documentos utiles para entender la evolucion del
proyecto, pero que ya no deben actuar como referencia viva de trabajo.

## Criterio de archivo aplicado

Se han movido aqui documentos que cumplen al menos una de estas condiciones:

- describen una sesion concreta ya cerrada;
- recogen una propuesta ya implantada o descartada;
- reflejan una arquitectura o estructura de carpetas superada;
- mezclan alcance activo con modulos fuera de la prioridad actual;
- duplican otra documentacion viva que ya cumple mejor la misma funcion.

## Regla de uso

Si un documento de este directorio vuelve a ser necesario como fuente activa,
debe reescribirse o promocionarse de nuevo a `docs/` o `specifications/`, pero
no reutilizarse sin revisar su vigencia.
