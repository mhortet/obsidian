# Documentación para el cliente

Esta carpeta contiene la documentación que se entregará al cliente para utilizar, administrar y mantener `srv-mm-01` y los servicios asociados. Está escrita para usuarios y responsables operativos; no es documentación de desarrollo.

## Estado de esta edición

La estructura está preparada, pero la entrega todavía es **provisional**. Se completará después de observar y validar en la sede la red, los puestos, el túnel, las identidades reales, las copias y las pruebas de aceptación.

No deben sustituirse los campos marcados como `PENDIENTE DE SEDE` por valores supuestos.

## Control de versiones

La versión entregada deberá quedar identificada en el acta, exportada a un formato de solo lectura y conservada sin modificaciones. Las actualizaciones posteriores producirán una nueva versión y un breve registro de cambios.

Esta carpeta no debe contener contraseñas, claves privadas, códigos TOTP, tokens, archivos `.env`, datos de pacientes ni información clínica.
