# Humanidades

Conceptos sobre filosofia, etica, cultura, politica, educacion, sentido del trabajo, condicion humana y lectura historica o social de la tecnologia.

Usar esta carpeta cuando el centro de gravedad de una nota no sea la tecnologia en si, sino lo que una tecnologia, institucion o decision implica para las personas, la sociedad, el conocimiento, el poder o la forma de vivir.

## Criterio de uso

- Si el foco es capacidades, arquitectura o herramientas de IA, usar [[../ia/README|IA]].
- Si el foco es reglas, cumplimiento, seguridad, permisos o calidad, usar [[../gobierno/README|Gobierno]].
- Si el foco es el sentido, la conciencia, la dignidad, la educacion, el poder politico, la cultura o el lugar de lo humano, usar Humanidades.
- Una nota puede estar en Humanidades y llevar etiquetas de IA, gobierno o sanidad si el tema es transversal.
