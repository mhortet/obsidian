# Gobierno

Conceptos que ordenan, limitan o gobiernan sistemas, proyectos y decisiones.

Incluye seguridad, calidad, normativa, criterios de validacion, permisos, trazabilidad, gobierno de datos, arquitectura de control y reglas que condicionan como debe operar un proyecto.
