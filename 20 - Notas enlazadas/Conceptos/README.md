# Conceptos

Aqui viven ideas reutilizables: definiciones, patrones, criterios, tecnicas y aprendizajes que merecen sobrevivir a una fuente concreta.

Una buena nota conceptual debe responder:

- Que significa.
- Para que sirve.
- En que contexto se usa.
- De que fuentes o experiencias procede.
- Con que otras notas se relaciona.
