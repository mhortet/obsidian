# 7 MCP que mejoran tu IA para programar

## Resumen ejecutivo

Fuente orientada a catalogar MCP utiles para desarrollo asistido por IA. Presenta herramientas para documentacion actualizada, gestion de tareas, GitHub, testing, Supabase, PostgreSQL, seguridad de codigo, memoria, busqueda web y navegador.

El interes para la boveda no esta en aceptar la lista como recomendacion cerrada, sino en extraer una taxonomia practica de herramientas agénticas: contexto documental, repositorio, datos, pruebas, seguridad, navegador, tareas y memoria.

## Ideas clave

- La IA que programa sin contexto actualizado "adivina" mas de lo deseable.
- Context7 se cita para consultar documentacion actualizada de frameworks y paquetes.
- Notion/Jira u otros gestores pueden convertir analisis de proyecto en tareas, pero requieren supervision humana.
- GitHub MCP permite trabajar con issues, ramas, pull requests y estado del repositorio; la fuente tambien menciona GitHub CLI como alternativa para ahorrar tokens.
- TestSprite se presenta como herramienta para generar y ejecutar tests a partir del codigo base.
- Supabase y PostgreSQL MCP permiten inspeccionar esquemas, relaciones y datos; la fuente advierte contra usarlos directamente en produccion.
- Semgrep MCP se presenta como apoyo para deteccion de vulnerabilidades y malas practicas.
- Playwright y Chrome DevTools pueden ayudar a un agente a validar frontend interactuando con navegador.
- Herramientas de memoria y busqueda pueden aportar continuidad y contraste tecnico.

## Implicaciones

- Conviene seleccionar MCP por flujo de trabajo, no por acumulacion de conectores.
- Las herramientas con escritura o acceso a datos deben quedar aisladas en desarrollo antes de cualquier uso productivo.
- Para QontrolMed y proyectos sanitarios, los MCP de base de datos solo deberian probarse sobre datos no sensibles, anonimizados o entornos de desarrollo.
