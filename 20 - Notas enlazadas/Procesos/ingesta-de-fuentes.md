# Ingesta de fuentes

## Flujo recomendado

1. Capturar la fuente en `raw/sources/`.
2. Crear una ficha con la plantilla `Plantilla Fuente`.
3. Resumir sin mezclar opinion propia.
4. Extraer ideas clave.
5. Anotar implicaciones practicas.
6. Enlazar conceptos, entidades, proyectos o sintesis.
7. Registrar dudas, contradicciones y caducidad.
8. Actualizar `00 - Sistema/meta/registro-fuentes.csv` si la fuente queda consolidada.
9. Actualizar `00 - Sistema/log.md` si la ingesta es relevante.

## Regla para Web Clipper

Web Clipper debe usarse como entrada, no como destino final. Una captura importante no esta terminada hasta que queda conectada con la capa curada.
