# raw

Carpeta para fuentes crudas, capturas originales y adjuntos de entrada.

- `sources/`: fuentes documentales capturadas con Web Clipper, transcripciones, paginas web, PDFs convertidos o notas importadas.
- `assets/`: adjuntos originales asociados a fuentes o ingestas.

Regla: el material de `raw/` se preserva. Si hay que corregir, se crea una nota procesada o una nueva version; no se reescribe silenciosamente la fuente original.
